# Iris Flower Classification

## Objective
Build a Machine Learning model to classify iris flowers into:
- Setosa
- Versicolor
- Virginica

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Model
Random Forest Classifier

## Outcome
The model successfully classified iris flower species with high accuracy.
